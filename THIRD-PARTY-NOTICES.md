# Third-party notices

`@pomwik/afterdb` ships the prebuilt binaries of `realm@20.2.0` as published upstream:

- the realm-core engine, version 20.1.0 (github.com/realm/realm-core, tag `v20.1.0`, commit `15493076`, Apache-2.0):
  `prebuilds/apple/realm-core.xcframework` and `prebuilds/android/<abi>/lib/*.a`, with their headers;
- the Node binaries `prebuilds/node/<platform>-<arch>/realm.node`, which contain realm-core and the realm-js Node
  binding.

realm-core includes the third-party code listed below, from its `src/external/` folder and its generated query
parser; realm-core's own list is the `THIRD-PARTY-NOTICES` file of its repository. The headers of these components
also ship in `prebuilds/apple/realm-core.xcframework/*/Headers/external/` (and `mpark` in
`prebuilds/android/<abi>/include/external/`). Some components are compiled only on some platforms: the SHA-1 and
SHA-2 code, for example, only where neither the system nor a dependency provides one (SHA-2 also on Windows).

The only change made to this code is the header fix in `Headers/external/s2/base/macros.h`, listed in
`CHANGES-FROM-UPSTREAM.md`. The Apache License 2.0 text is in `LICENSE`.
