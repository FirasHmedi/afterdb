# @pomwik/afterdb-react

The `@realm/react` 0.20.0 hooks for Realm® (RealmProvider, useQuery, useObject, useRealm), repackaged for
@pomwik/afterdb, with `react-native` as an optional peer dependency instead of a nested copy (realm/realm-js#7066).
Use it through an npm alias: `"@realm/react": "npm:@pomwik/afterdb-react@0.20.2"`, next to
`"realm": "npm:@pomwik/afterdb@20.3.1"`. Changes: see CHANGES-FROM-UPSTREAM.md.
