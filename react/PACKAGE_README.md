# @pomwik/afterdb-react

The `@realm/react` 0.20.0 hooks (RealmProvider, useQuery, useObject, useRealm), repackaged for @pomwik/afterdb.
Use it through an npm alias: `"@realm/react": "npm:@pomwik/afterdb-react@0.20.1"`. Changes: see CHANGES-FROM-UPSTREAM.md.
